Your arrow function has curly braces {}, which means it's a block body. When you use a block body, you need to explicitly write return. Without it, the function returns undefined for every user, and filter treats that as falsy — so nothing gets kept.

// ❌ Your version — no return, so filter gets nothing
const AdultActive = users.filter((user) => {
    (user.active == true) && (user.age >= 18);  // result is just... dropped
});

// ✅ Fix — add return
const AdultActive = users.filter((user) => {
    return (user.active == true) && (user.age >= 18);
});

reduce takes two parameters in the callback:

accumulator — the running total you're building up
current — the current item in the array

jsusers.reduce((accumulator, current) => ...)

const activeCount = users.reduce((count, user) => {
  if (user.active) {
    return count + 1;  // user is active, add 1
  }
  return count;        // not active, keep count as is
}, 0);  // ← start counting from 0

console.log("Active:", activeCount); // 3
The 0 at the end is the initial value — you're telling reduce "start my counter at zero." Without it, reduce uses the first item as the accumulator, which here would be a user object, not a number.
